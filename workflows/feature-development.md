# Workflow — Feature Development

1. Product Owner viết feature spec và acceptance criteria.
2. Solution Architect xác định module, contract và ADR nếu cần.
3. Security Reviewer đánh giá trust boundary.
4. Agent chuyên trách triển khai.
5. Database Agent review migration nếu có.
6. QA Agent tạo test matrix.
7. Code Reviewer review.
8. Chạy Definition of Done.
9. Merge sau khi contract/client generation sạch.

## Deliverables

- Feature spec.
- Code.
- Test.
- Migration.
- Contract update.
- Documentation.
- Handoff.
