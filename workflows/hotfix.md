# Workflow — Hotfix

1. Xác nhận mức độ nghiêm trọng.
2. Tạo branch hotfix.
3. Viết test tái hiện tối thiểu.
4. Sửa phạm vi nhỏ.
5. Security review nhanh.
6. Build/test bắt buộc.
7. Deploy canary nếu có.
8. Theo dõi metric.
9. Merge ngược về nhánh phát triển.
10. Viết postmortem nếu ảnh hưởng dữ liệu hoặc người dùng.
