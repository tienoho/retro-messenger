# Workflow — Code Review

1. Đọc task/acceptance criteria.
2. Đọc diff tổng thể.
3. Kiểm tra breaking change.
4. Kiểm tra authorization.
5. Kiểm tra transaction/idempotency.
6. Kiểm tra failure/retry.
7. Kiểm tra performance.
8. Kiểm tra test.
9. Kiểm tra docs/migration.
10. Kết luận approve/request changes.
