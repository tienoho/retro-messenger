# Pull Request Checklist

- [ ] PR có mô tả mục tiêu.
- [ ] Phạm vi thay đổi nhỏ và rõ.
- [ ] Không chứa secret.
- [ ] Không sửa generated code thủ công.
- [ ] Không thêm dependency trùng chức năng.
- [ ] Build/test pass.
- [ ] Breaking change được ghi rõ.
- [ ] Migration có compatibility note.
- [ ] UI có loading/error/empty/offline state.
- [ ] Security impact đã xem xét.
