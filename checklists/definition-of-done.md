# Definition of Done

- [ ] Acceptance criteria được đáp ứng.
- [ ] Không phá vỡ kiến trúc.
- [ ] Authorization được kiểm tra ở backend.
- [ ] Error path được xử lý.
- [ ] Unit test đã có.
- [ ] Integration/E2E test phù hợp đã có.
- [ ] Migration và index đã review nếu cần.
- [ ] OpenAPI/realtime contract đã cập nhật.
- [ ] Generated client đã cập nhật.
- [ ] Log không chứa secret.
- [ ] Telemetry cần thiết đã có.
- [ ] Documentation đã cập nhật.
- [ ] Rollback hoặc feature flag đã xác định.
