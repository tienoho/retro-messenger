# Implementation Roadmap

## Milestone 1 — Starter hiện tại

- In-memory .NET API.
- SignalR.
- Node zero-dependency demo.
- Web/Admin/Electron/Mobile skeleton.
- PostgreSQL schema.
- Agent pack.

## Milestone 2 — Persistence

- EF Core + Npgsql.
- OpenIddict + Identity.
- Transactional outbox.
- Redis presence.
- Integration tests với Testcontainers.

## Milestone 3 — Client offline

- IndexedDB/SQLite.
- Local outbox.
- Sync cursor.
- Push notification.
- Multi-device receipts.

## Milestone 4 — Yahoo-like experience

- Buzz.
- Invisible.
- Contact groups.
- Classic theme.
- Sticker/Audible.
- Public rooms.

## Milestone 5 — Media and calls

- MinIO/R2 upload.
- ClamAV/FFmpeg worker.
- LiveKit token service.
- Mobile incoming call integration.
