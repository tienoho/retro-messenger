## Gemini CLI usage

- Project subagents are in `.gemini/agents/`.
- Shared Agent Skills are in `.agents/skills/`.
- Run `/agents reload` after changing agent definitions.
- Run `/skills reload` after changing skills.
- Use `@agent-name` to request a specialist explicitly.
- Review tool confirmation prompts and keep the repository in a trusted workspace only.
